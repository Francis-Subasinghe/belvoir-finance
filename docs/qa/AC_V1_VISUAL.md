# Acceptance criteria: V1 visual layer

**Task:** V1, added by Atlas after F3 and before F4: "a visual pass" giving the site original illustrations, story cover art, charts and diagrams in the demo stories, an icon set and subtle CSS-only motion, without giving up the F1 to F3 quality bar (no JavaScript, no third-party assets, Lighthouse budgets, WCAG 2.2 AA). It also folds in the F2 `SourceNote` spacing fix ("Source:Example" renders with no space after the colon, raised by Atlas on PR #22 under F3-05).
**Verifier:** Sentinel. **Also checked by:** Atlas (design fit and wireframe order, V1-48; asset provenance sign-off, V1-03; the decisions in the Open Questions table), Aegis (the SVG check in V1-05 to V1-13 is Aegis's design; CSP and rendering safety, V1-46), Launchpad (Lighthouse and visual-regression gates, V1-32 to V1-38 and V1-50 to V1-52).
**Status:** Draft v0.2 (5 Oct 2026). v0.1 was written on `main` at `c0b2f44` (PR #20 merged), against the F3 code on PR #22's head `690ca3b` (`feat/f3-pages`). It assumes #22 is merged: every F3 file, component and test it names (`StoryCard`, `ArticleHeader`, `SourceNote`, `ChartWrapper`, `PLACEHOLDER_PAGES`, `VISUAL_PAGES`, the F3-41 baseline process, the F3-51 faked-clock build) is on `main` once #22 lands. v0.1 folded in Atlas's CLS and motion decisions and Aegis's SVG check. v0.2 marks Q-1 to Q-8 as decided (Atlas accepted every proposed default), applies Aegis's answers on A-1 to A-4 and the Markdoc `chart` tag schema, adds Atlas's no-blink rule for the stagger and the layout fixes that go with the `SourceNote` fix, and amends F3-39 (see Changelog). Follows `AC_F2_DESIGN_SYSTEM.md`, `AC_F3_PAGES.md`, `TEST_STRATEGY.md`, `ADR-0001-platform.md` (security requirement 2, strict CSP), `ADR-0002-brand-colour-type.md` (navy, gold and slate, the gold rule and the three self-hosted families), `docs/design/CONTRAST.md`, `docs/design/DESIGN_SYSTEM.md` and `AGENTS.md`.

Each criterion has a check type and the evidence that goes in the PR:

- **Unit:** Vitest, merge-blocking in CI. Evidence: the test name and the CI run link.
- **Build:** an assertion on `dist/` (or on a fixture build) in `tests/build/`, merge-blocking in CI. Evidence: the test name and the CI run link.
- **E2E:** Playwright plus `@axe-core/playwright` at 360, 768 and 1280 px against the built site (and the gallery test build, F2-01), merge-blocking in CI. Evidence: the test name and the CI run link.
- **CI (Lighthouse) / E2E (blocking visual):** the blocking `Lighthouse` and `Visual regression` jobs from PR #20. Evidence: the run link and summary.
- **Manual:** recorded in the PR with the commit tested, browser and viewport, plus screenshots where stated.

Every automated check that guards a rule has a **negative fixture** that must fail **the real check** (the same exported function, scan or build step CI runs), so a check that matches nothing can't pass vacuously (`AGENTS.md` rule 7). Fixtures live under `tests/fixtures/v1/` and never in `src/` or `content/`, so they can't reach `dist/`. Every test name starts with its V1 ID (for example `V1-08 foreignObject fails`). Criteria shaped by a decision cite it as **(decided, D-n)**, **(decided, Q-n)** or **(decided, A-n)**.

## What the code does today (F3 at `690ca3b`)

- **No art.** The only committed SVG is `public/favicon.svg`. `ChartWrapper` (F2-26) draws an inline, `aria-hidden` SVG with a data table as the text equivalent; it appears only in the gallery, never in a story. The Markdoc allowlist is exactly `callout` (F3-39).
- **Motion.** Tokens `--motion-duration-fast` (120 ms), `--motion-duration-base` (200 ms) and `--motion-ease-standard` exist (F2-32). `global.css` has the F1 rule that sets `animation: none !important` and `transition: none !important` on everything under `prefers-reduced-motion: reduce`. No `@keyframes` exist.
- **Budgets.** `tools/lighthouse/budgets.json`: each category ≥ 0.9 (actual: 100 everywhere locally), LCP < 2500 ms, CLS ≤ 0.1, TBT < 200 ms, scripts ≤ 50 KB editorial and 0 on `/tools/cash-vs-profit/`. No image budget. `lighthouserc.cjs` audits every page in `dist-lhci/` (`listPages`), median of 3 runs. SEO is skipped only for the `belvoir-demo` marker and `SEO_EXEMPT_PATHS` (`/404.html` plus `PLACEHOLDER_PAGES`).
- **Visual.** `playwright.visual.config.ts` sets `animations: "disabled"` and `pages.visual.ts` emulates `reducedMotion: "reduce"`. Baselines are blocking (#20) and come only from CI (F3-41).
- **`SourceNote`** puts `<span>Source:</span>` and the link on separate lines, so the rendered text is "Source:Example…".
- **CLS.** On #22, `/explore/` fails at 0.108 (D-3). V1 doesn't own that fix, but it must not add to it.
